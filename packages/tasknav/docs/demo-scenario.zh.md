# tasknav 演示场景：电影媒资上架流程

> 面向新会话的验证脚本。前提：tasknav 插件已激活（动态版或静态安装 `dsh-plugin` 仓库的 packages/tasknav），composer 上方出现「任务导航」dock。

## 场景设定

你扮演运营角色，操作管理后台的内容上架流程：

```
① 选料 → ② 媒资加工（改标题 / 选海报）→ ③ 橱窗编排 → ④ 其他配置与发布
```

各模块有 CLI（演示中由模型模拟命令，不真执行）。

## 验证脚本（按序发给新会话）

### 第 1 步 · 建流程

> 我是运营，要上架一批电影媒资。流程是：选料、媒资加工（改标题、选海报）、橱窗编排、其他配置发布。用任务树把这个流程建出来。

**预期**：模型调用 `task_tree` create + add 建出 7 节点树；**dock 在 3 秒内自动出现整棵树**（无需手动刷新），状态徽章、完成度计数（0/7）就绪。

### 第 2 步 · 落一个决策

> 选料完成了。改标题这事我定了：用《午夜巴黎·4K 修复版》这个方案，强调修复版稀缺性。

**预期**：`step-1` 变 ✓ 划线；`改标题` 节点出现绿色「已决策 1」徽章——**悬停徽章能看到决策全文与时间**。

### 第 3 步 · 制造待决策

> 海报还没定，竖版官方图和自制横版二选一，先记着。

**预期**：`选海报` 出现虚线「待决策 1」徽章（呼吸动画）；详情面板（点击该节点）列出问题。

### 第 4 步 · 验证防遗忘（关键）

> （聊几句无关的，比如"帮我看看今天星期几"，然后问）现在改标题定的是什么方案来着？

**预期**：模型直接回答"《午夜巴黎·4K 修复版》，强调修复版稀缺性"——**不需要重新问**。因为决策已落档，`task_tree` 的 context 返回值随时可查（`action=tree`），不依赖对话记忆。

### 第 5 步 · 验证话题锁定

> （在 dock 里点击"选海报"节点聚焦）

**预期**：节点高亮 + 顶部出现聚焦 chip「◉ 选海报」；随后对话模型应围绕海报展开（你问"这个怎么处理"，它谈海报二选一的待决策项，而不是泛泛而谈）。

### 第 6 步 · 收尾决策与状态流转

> 海报用自制横版。编排进本周推荐位第一期。

**预期**：`选海报` 待决策徽章消失、新增决策记录；`③ 橱窗编排` 转 active/running；完成度计数上涨（如 3/7）。

## 已知边界

- 动态版树存内存：**DSH 进程重启会丢**（页面刷新不丢）；静态版落盘 `.tasknav/`，重启恢复
- 全局单树：多会话共享同一棵树（有意设计：运营主线跨会话）；需要隔离时说一声可切换为按会话存储
- 轮询间隔 3 秒：极快连续操作下最多延迟一拍
